# 📖 مكتبة الطريقة الجامعة الرقمية (PWA)

مرجع إيماني وفقهي شامل يضم 75 كتاباً وكتيباً ومصباحاً للشيخ **أحمد مصطفى محمد مصطفى (أحمد البسفي)**، بالإضافة إلى الأوراد الشريفة المباركة (**دلائل الخيرات** للإمام الجزولي و**فيض المنان** للشيخ جابر البغدادي).

## 💡 تنويه الأمانة العلمية وحفظ الحقوق
* **التطبيق:** مجهود شخصي ونشر غير رسمي موجّه للقراءة والذكر والتيسير.
* **المحتوى:** تم تجميع النصوص والكتيبات بحرص للحفاظ على النص كما هو دون أي تغيير.

## ✨ المميزات الفنية:
* **تطبيق ويب تقدمي (PWA):** قابل للتثبيت على الهواتف الذكية.
* **عمل أوفلاين 100%:** قراءة كافة الكتب والـ PDF بدون الحاجة لاتصال بالإنترنت.
* **قراءة الأوراد اليومية:** أزرار تفاعلية للانتقال الفوري لأحزاب الأيام والأوراد المباركة.
* **وضع القراءة الليلية:** دعم كامل للوضع الداكن (Dark Mode) المريح للعين.
