# 📚 منصة إقرأ (إقرأ باسم ربك)

منصة إلكترونية تعليمية تفاعلية مصممة هندسياً لتستوعب مكتبة متنامية من الكتب (تستهدف 100 كتاب وأكثر) موجهة للطلاب والناشئة، بأسلوب قراءة سلس ونوافذ تفاعلية تدعم التدبر وفهم النصوص.

---

## ✨ مميزات المنصة
* **هندسة قابلة للتوسع (Scalable & Decoupled):** فصل تام بين التصميم البرمجي ومحتوى الكتب عبر ملفات JSON لتسهيل إضافة وإدارة الكتب.
* **مكتبة رئيسية ببحث فوري:** تتيح للمستخدم تصفح الكتب والبحث السريع بين العناوين والمؤلفين.
* **قارئ تفاعلي ذكي (`reader.html`):** قالب موحد يتعامل ديناميكياً مع أي كتاب يتم فتحه ويعرضه مقسماً إلى نوافذ وفصول.
* **تصميم إسلامي هادئ ومتجاوب:** ملائم لجميع الأجهزة (حواسيب، أجهزة لوحية، وهواتف ذكية) بألوان مريحة للعين.
* **استضافة مجانية وسريعة:** تعمل بالكامل على **GitHub Pages** دون الحاجة لخوادم مدفوعة.
